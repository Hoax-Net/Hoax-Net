### Who is `blackmagic`?

I'm a **Cybersecurity Operations Manager** with **17 years of technical experience** spanning software development, systems, troubleshooting, security research, automation, and technology operations.

That experience has shaped the way I approach cybersecurity:

> **Understand how systems work. Understand how they fail. Then build better ways to protect them.**

My interests sit at the intersection of **cybersecurity operations, ethical hacking, security research, software development, automation, and open-source technology**.

I enjoy taking complicated technical problems and turning them into practical solutions, useful documentation, security tooling, and knowledge that other people can learn from.

**Based in the Midwest, USA.**

## `02` — Mission

<div align="center">

### `SIMPLIFY • SECURE • BUILD • SHARE`

</div>

My goal is simple:

**Make complicated technology easier to understand while encouraging responsible security research and open-source collaboration.**

I believe some of the strongest security communities are built when people are willing to:

- 🔍 **Investigate** how technology actually works
- 🛡️ **Defend** systems against real-world threats
- 🧪 **Research** vulnerabilities responsibly
- 💻 **Build** useful software and security tooling
- 📚 **Document** what we learn
- 🌐 **Share** knowledge with the community
- 🐙 **Contribute** to open-source projects
