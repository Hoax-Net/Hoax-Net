## 🧠 About Me

With **17 years of technical experience**, I've spent my career exploring how technology works, how it fails, and how it can be made more secure. That experience ultimately led me into my career as a **Cybersecurity Operations Manager**, where technology, security operations, problem solving, and continuous learning come together.

I'm passionate about **cybersecurity, security research, software development, ethical hacking, automation, and open-source projects**. I enjoy taking complicated technical problems, breaking them down into understandable pieces, and building practical solutions that help people learn, troubleshoot, and work more securely. My interests span defensive security and offensive-security concepts, with an emphasis on responsible research, education, and authorized testing.
